# NIKKE Archive

승리의 여신: 니케 팬 아카이브 사이트입니다.

🔗 **https://nikkearc.vercel.app**

---

## 참고

니케별, 스킬레벨, 오버로드, 큐브 셋팅등을 간략하게 보실 수 있는 정보 입니다.

절대적인 수치는 아니며 보유한 캐릭터풀, 재화 등에 따라 적당히 타협하시길 권장 드립니다.

표기가 잘못 되어 있거나 최신화가 안되어 있을 경우 요청해 주시면 반영 하도록 하겠습니다.

신규 니케 출시 마다 업데이트 될 예정

## 기능

**육성 가이드**
캐릭터별 스킬 레벨 권장 수치와 육성 우선순위를 확인할 수 있습니다.

**라이브 2D 뷰어**
인게임 Spine 모델을 브라우저에서 직접 감상하고 다양한 포즈를 확인할 수 있습니다.

**도구 모음**
전초기지 수익 계산기, 싱크로 비용 계산기를 제공합니다.
